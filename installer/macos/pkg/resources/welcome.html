Rezen Backup

Encrypted, offline backups to an external drive. Everything is encrypted on this Mac before it is written to the backup drive.

This installer puts Rezen Backup in your Applications folder. If an older version is running, it is closed first. A backup that was in progress is kept as unfinished and runs again next time.

Rezen Backup works entirely offline. It never uploads your files, file names, passwords or keys.
